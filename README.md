# Kynova en 3D

Recorrido interactivo, paso a paso, de cómo un archivo Kynova (`.kyn`) se vuelve Chapín (`.gt`): tokens, árbol, tipos, tabla de símbolos y traducción, con los datos reales del compilador. Incluye una guía de uso y un glosario.

Es una página estática (`index.html`). Para verla, abrirla en el navegador.

Para publicarla en un VPS con Coolify, ver [`DEPLOY.md`](DEPLOY.md). En este repositorio el *Base Directory* es `/`.
